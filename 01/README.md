# 숫자 맞추기 CLI 게임 (Number Guessing Game)

사용자가 프로그램 시작 시 터미널에서 직접 숫자 범위와 제한 기회 횟수를 인자로 지정하여, 동적으로 난이도를 조절할 수 있는 콘솔(CLI) 기반 프로그램입니다.

---

## 과제 핵심 구현 항목

1. CLI 기반: input()과 print()를 활용한 텍스트 기반 콘솔 인터페이스 구현
2. 동적 명령행 인자(sys.argv) 처리: 실행 시점에 사용자가 입력한 인자값을 내부 변수로 흡수하여 난이도 설정
3. 견고한 예외 처리: 잘못된 실행 명령어, 입력 오류 등 발생 가능한 모든 예외 상황에 대처하여 프로그램 안정성 확보

---

## 상세 실행 방법 및 명령어 안내

이 프로그램은 파일 이름 뒤에 [최대 숫자 범위]와 [제한 기회 횟수]를 띄어쓰기로 구분하여 반드시 함께 입력해야 합니다.

### 1. 일반적인 실행 방법 (과제 표준 예시)
터미널에서 game.py 파일이 있는 01 폴더로 이동한 후 아래 명령어를 입력합니다.

python3 game.py 1000 5

* 동작 원리: 1부터 1000 사이의 정수 중 정답이 무작위로 지정되며, 총 5번의 기회와 100점의 초기 점수가 주어집니다.

### 2. 다양한 난이도 응용 실행 예시
* 쉬운 난이도: python3 game.py 50 10 (범위는 좁게, 기회는 많이)
* 높은 난이도: python3 game.py 5000 3 (범위는 넓게, 기회는 적게)

## 예외 처리 (Error Handling) 안내

사용자가 잘못된 값을 입력했을 때 프로그램이 강제 종료되지 않도록 철저하게 예외 처리가 되어 있습니다.

### 1. 실행 인자를 입력하지 않았거나 부족할 때
인자가 부족하면 가이드를 출력한 후 안전하게 종료됩니다.
* 실행 명령어: python3 game.py
* 출력 에러 메시지:
실행 방법이 올바르지 않습니다.
사용법: python3 game.py [범위] [기회]
예시: python3 game.py 1000 5

### 2. 숫자가 아닌 문자열을 인자로 넣었을 때
실행 인자에 문자를 넣은 경우, 에러 메시지를 출력하고 예외 처리합니다.
* 실행 명령어: python3 game.py 천 오
* 출력 에러 메시지:
❌ 실행 방법이 올바르지 않습니다.
💡 사용법: python3 game.py [범위] [기회]
💻 예시: python3 game.py 1000 5

### 3. 게임 중 숫자가 아닌 문자를 잘못 입력했을 때
게임 도중 문자를 입력했을 때 기회를 차감하지 않고 경고 메시지를 띄운 후 다시 입력을 받습니다.
* 출력 예시:
숫자를 입력하세요 (종료하려면 q): hello
오류: 숫자만 입력 가능합니다.

남은 기회: 5
숫자를 입력하세요 (종료하려면 q): 

### 4. 중도 포기 및 종료 기능
게임 도중 언제든지 'q' 또는 'Q'를 입력하면 시스템이 안전하게 종료됩니다.
* 출력 화면:
숫자를 입력하세요 (종료하려면 q): q
프로그램을 종료합니다.
